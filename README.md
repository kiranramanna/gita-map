# Gita Map

A connected study companion for the **Srimad Bhagavad Gita** lecture series by **Advaita Retold**.

Source playlist: https://www.youtube.com/playlist?list=PLxtfkA7EyYFPx8caX0IQ3o1TszTBDw8uO

## Intended experience

- One post per episode, with a summary that stays close to the teacher’s wording, vocabulary, and reasoning.
- A logical block diagram for each lecture.
- Continuous reading with a persistent left navigation rail organized as Chapter → Episode → Shloka, highlighting the current section while scrolling.
- A growing knowledge graph connecting concepts, shlokas, scripture references, and lectures.
- Transcript passages and video timestamps supporting summaries and graph relationships.
- Explicit distinctions between the teacher’s stated connections and inferred connections; unclear references remain marked for clarification.
- Source-grounded questions and answers, with unresolved questions available for discussion with the teacher.
- A distinct visual design from Thinkit, hosted on GitHub Pages.

## Design references under consideration

- [Quartz](https://quartz.jzhao.xyz/): linked notes, nested navigation, and graph exploration.
- [Cytoscape.js](https://js.cytoscape.org/): interactive knowledge graph.
- [Mermaid](https://mermaid.js.org/): lecture diagrams.

The site framework is not selected yet. Transcript ingestion, content generation, and interactive question answering are not implemented.
